# DS_2
Repozitorijum za materijale iz kursa Diskretne strukture 2 za I - smer na Matematickom fakultetu

NAPOMENA: ako se bilo koji pdf ne otvara u okviru Github-a, samo ga lokalno preuzeti sa Github-a na Desktop ili bilo koji drugi direktorijum po zelji i onda ce biti dostupan za upotrebu.

Linux OS: Ctrl + Alt + T => cd Desktop => git clone https://github.com/lukamijailovicmatf/DS_2.git
Nakon komande 'git clone ...' iz terminala i njenog zavrsetka citav repozitorijum se nalazi na Desktop-u lokalno
i svi folderi/fajlovi/pdf-ovi su dostupni za dalju upotrebu.
